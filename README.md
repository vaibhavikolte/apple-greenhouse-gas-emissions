# Apple Greenhouse Gas Emissions Analysis

## Project Overview
This project analyzes Apple's greenhouse gas emissions using Power BI. The dashboard presents emission trends, scope and source analysis, product carbon footprint, and growth versus sustainability.

## Dashboard Pages
1. **Executive Overview** — Key emission indicators and an overall summary.
2. **Emission Analysis** — Emission trends and comparisons.
3. **Scope and Source Analysis** — Analysis by emission scope and source.
4. **Product Carbon Footprint** — Product-level carbon footprint analysis.
5. **Growth vs Sustainability** — Comparison of business growth and sustainability trends.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization
- KPI Analysis
